## Website Color Palette

Use this muted palette consistently across the website for a calm, premium feel. Keep the large areas light and reserve antique gold for small accents.

| Color | Hex | Intended use |
| --- | --- | --- |
| Muted ocean blue | `#456B79` | Primary links, buttons, and selected states. Use white text on filled blue controls. |
| Sage green | `#58715D` | Secondary actions and positive states. Use white text on filled green controls. |
| Antique gold | `#B79A5B` | Small decorative accents and focus outlines; avoid using it for text. |
| Page background | `#F5F7F6` | Main page background. |
| Header background | `#EAF0EE` | Soft blue-green tint that distinguishes the header from the page. |
| Surface | `#FFFFFF` | Content areas, cards, and form surfaces. |
| Main text | `#263238` | Headings and body text. |
| Secondary text | `#59666A` | Supporting text and less prominent labels. |
| Borders | `#D9E2DE` | Dividers, input borders, and subtle outlines. |

Use the tinted header and page backgrounds for broad surfaces, dark text for readability, and the accent colors sparingly. Maintain clear contrast for interactive controls and visible keyboard focus states.
